Arquivo → classe → responsabilidade
ArquivoClasse / structResponsabilidade
main.cpp—Cria FirstApp e chama run().
first_app.*FirstAppCamada de aplicação: loop principal, pipeline layout, command buffers, orquestra o resto.
crs_window.*CrsWindowJanela GLFW, surface Vulkan, rastreio de redimensionamento.
crs_device.*CrsDeviceInstance, validation layers, physical/logical device, command pool, helpers de buffer/imagem.
crs_swap_chain.*CrsSwapChainSwap chain, render pass, framebuffers, recursos de profundidade, sincronização CPU/GPU.
crs_pipeline.*CrsPipeline / PipelineConfigInfoShader modules e o VkPipeline gráfico (estado fixo + dynamic state).
crs_model.*CrsModel / VertexBuffer de vértices (posição + cor) de um modelo.
shaders/*.vert, *.frag—Shaders GLSL, compilados pra .spv pelo CMake.
